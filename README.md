# ☕ Coffee Shop Sales Analysis Dashboard

## 📌 Project Overview

This project presents an interactive Coffee Shop Sales Dashboard developed using Microsoft Excel.

The dashboard helps analyze sales performance, customer footfall, product demand, store performance, and customer purchasing behavior.

The objective is to transform raw sales data into actionable business insights for better decision-making.

---

## 🎯 Objectives

- Analyze total sales performance
- Understand customer footfall patterns
- Identify top-selling products
- Evaluate store-wise performance
- Analyze sales trends by hour and day
- Understand category-wise sales contribution

---

## 📂 Dataset Information

- Source: Coffee Shop Sales Dataset
- Tool Used: Microsoft Excel
- Records: Coffee shop transaction data
- Data Includes:
  - Transaction ID
  - Product Category
  - Product Name
  - Store Location
  - Sales Amount
  - Order Quantity
  - Date and Time Information

---

## 🧹 Data Cleaning & Preparation

- Removed duplicate records
- Checked missing values
- Formatted date and time fields
- Created Pivot Tables
- Built interactive dashboard using charts and slicers

---

## 📊 Dashboard Overview

![Dashboard Overview](Dashboard%20Screenshots/Dashboard-Overview.png)

### Dashboard Features

### 1. Sales KPIs
- Total Sales
- Total Footfall
- Average Bill Per Person
- Average Orders Per Person

### 2. Quantity Ordered Based on Hours
Analyzes customer purchasing activity throughout the day.

### 3. Category-wise Sales Distribution
Shows contribution of each product category to overall sales.

### 4. Size Distribution Based on Orders
Analyzes customer preferences for different beverage sizes.

### 5. Store Performance Analysis
Compares sales and footfall across different store locations.

### 6. Top 5 Products by Sales
Highlights the best-performing products.

### 7. Orders by Day
Analyzes customer ordering behavior across weekdays.

---

## 💡 Key Insights

- Morning hours generate the highest order volume.
- Coffee category contributes the largest share of sales.
- Sales performance varies across store locations.
- A few products contribute significantly to total revenue.
- Weekday customer traffic is higher than some weekend periods.
